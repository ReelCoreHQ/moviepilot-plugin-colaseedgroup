# 可乐PT 保种组 · 团队说明

> 2026-11-22 定稿 ｜ 面向运营 / 工作组 / 管理团队
> 插件仓库：https://github.com/ReelCoreHQ/moviepilot-plugin-colaseedgroup

---

## 一、这是什么

站点有一批**官方种子**，需要有人长期挂在下载器里做种，否则老种会断种、下载的人拿不到速度。

**保种组就是干这件事的岗位**：成员把站点官方池按档位搬进自己的下载器长期保种，站点按月给他瓶盖奖励，保满年限后退休，保留一揽子永久权益。

和「辅种」的区别：

| | 辅种 | 保种组 |
|---|---|---|
| 干什么 | 我已有的资源，去站点找同款补种 | 站点要的资源，我搬过来保着 |
| 门槛 | 所有会员 | 需要审核授予 |
| 有没有奖励 | 只有做种积分 | 做种积分 **+ 月度岗位奖励** |
| 有没有考核 | 没有 | 每月要保够时长，否则清退 |

---

## 二、两种用法（同一份代码）

| 形态 | 适合谁 | 怎么装 |
|---|---|---|
| **MoviePilot 插件** | 已经有 MP 的用户 | MP → 插件市场 → 添加仓库 → 装「可乐保种组」 |
| **独立 Docker 服务** | 不想装 MP，只要保种 | `docker compose up -d`，面板在 **3006** 端口 |

两种形态跑的是同一份代码，功能一致。独立版**不含** MP 的加种后自动整理/刮削/订阅——那些是 MP 的职责。

## 三、申请条件

### 谁能用

**任何已完成注册的站点会员都能装插件、能保种、能看自己的数据。**

区别在于有没有「正式成员」身份：

| 状态 | 怎么来 | 能做什么 |
|---|---|---|
| **保种参与者** | 自己装插件、开启保种组 | 保种、上报、看自己的数据。**不计考核、不发奖励** |
| **保种组成员** | 覆盖达到门槛后，由组长或 admin 授予「工作组-保种」 | 以上全部 **+ 月度奖励 + 累计退休进度** |

### 门槛

```
当前覆盖 ≥ 2048 GiB（2T）
```

**不限天数**——保到了就自动进入「待授予」候选池。

### 谁能授予

**工作组-组长** 和 **admin**，在管理页面点「授予」即可。

## 四、档位与目标

| 档位 | 目标体积 |
|---|---|
| 2T / 5T / 10T / 15T / 20T | 2048 / 5120 / 10240 / 15360 / 20480 GiB |
| 自定义 | 自己填，支持 `100M` `100G` `1T` `1P`（不带单位按 GiB） |
| **全站官种** | 有多少保多少——目标 = 站点官方池总量，池子涨目标跟着涨 |

**「只能超，不能少」**：插件按最合适的组合挑种子，保证总量 ≥ 目标；单颗比剩余缺口还大时挑其中最小的那颗。

**只保官方种**，非官方一颗都不碰。

---

## 五、奖励措施（核心）

### 月度岗位奖励

**每月结算一次，按档位递增。**

| 档位 | 体积 | 岗位奖励/月 | 加上做种积分后 | 相对 2T |
|---|---|---|---|---|
| **2T** | 2,048 GiB | **80,000 瓶盖** | 202,651 | 1.00x |
| 5T | 5,120 GiB | **217,143 瓶盖** | 368,638 | 1.82x |
| 10T | 10,240 GiB | **462,160 瓶盖** | 624,207 | 3.08x |
| 15T | 15,360 GiB | **718,932 瓶盖** | 884,551 | 4.36x |
| **20T** | 20,480 GiB | **983,648 瓶盖** | 1,151,059 | **5.68x** |

**设计意图**：体积 10 倍 → 总收益 **5.68 倍**。

为什么不是线性 10 倍？因为站点的做种积分本身是「arctan 饱和」的——2T 到 20T 体积涨 10 倍，做种积分只多 37%。岗位奖励承担了拉开差距的职责，所以它的增长要**快于**体积才够吸引力。

### 连续达标加成

| 连续达标 | 加成 |
|---|---|
| 每满 3 个月 | +5% |
| 上限 | **+30%**（一年最多 +20%） |

### 举例

保 20T、连续达标 12 个月：

```
岗位奖励 983,648 × 1.20 ≈ 1,180,378 瓶盖/月
一年约 1,416 万瓶盖
```

（作为对照：站点当前平均账户余额约 2,066 万）

### 月度发放的前提

**当月「覆盖达标」的累计时长 ≥ 当月自然时长的 5/6**（约 25/30 天）。

不达标 → 当月岗位奖励不发，**但不追扣已到账的做种收益**。

## 六、退休机制

### 退休年限（按档位递减）

| 档位 | 退休年限 | 每月进度 |
|---|---|---|
| **2T** | **36 个月**（3 年） | 2.78% |
| 5T | 30 个月 | 3.33% |
| 10T | 24 个月 | 4.17% |
| 15T | 21 个月 | 4.76% |
| **20T** | **18 个月**（1.5 年） | 5.56% |

**「保得越多，退得越快」**——2T 要 3 年，20T 只要 1.5 年。

自定义档 / 全站官种按 5T（30 个月）计。

### 退休后得到什么

**移入「养老」组，权益与在岗完全相同**，区别只剩：

| | 在岗（工作组-保种） | 退休（养老） |
|---|---|---|
| 权益 | 13 项 | **13 项（完全相同）** |
| 每月保够 5/6 | **必须** | 不必 |
| 月度岗位奖励 | 拿 | 不拿 |
| 头衔 | 工作组-保种 | 养老 |

**这是刻意的设计**：在岗和为站点做过贡献的人享有**同样待遇**，区别只在于「还要不要每月履约」。

---

## 七、权益清单（在岗与退休同为 13 项）

| 权限 | 说明 |
|---|---|
| **下载不计量** | 下载不计入分享率统计 |
| **免分享率考核** | 不会因为分享率低被限制 |
| **免 H&R** | 不产生 H&R 义务 |
| **免盒子限制** | 不受盒子数量/并发限制 |
| **查看自己的保种数据** | 面板上的覆盖、时长、退休进度 |
| 下载 / 发种 | 正常权限 |
| 论坛发帖 / 回复 | 正常权限 |
| 求种 | 正常权限 |
| 图片上传 | 正常权限 |
| 读积分规则 | 正常权限 |
| **发邀请** | **数量不限** |

**不给的**：审核、封禁、论坛管理、API Key 等岗位/程序化权限——保种是执行岗，不是管理岗。

---

## 八、考核与退出

### 月度达标

```
当月「覆盖达标」的累计时长 ≥ 当月自然时长 × 5/6
```

- 只累计**覆盖达标**的相邻上报区间
- **单段按 7 小时封顶**——防止长时间不上报后补报刷时长
- 服务端自己算，**不采信插件自己报的结论**

### 未达标的后果

| 连续未达标 | 处理 |
|---|---|
| 第 1 个月 | 站内提醒，**不清退** |
| 第 2 个月 | **移出工作组-保种**（回到「参与者」状态） |

**被清退后 3 个月内不得再申请**。

3 个月后可以重新申请，从零开始累计退休进度。

### 防作弊

| 异常 | 判据 |
|---|---|
| 掉线 | 有客户端快照但一台都读不到 |
| 覆盖骤降 | 客户端可读、覆盖却掉一半以上 |
| 覆盖暴涨 | 体积涨 3 倍以上且最老那颗做种时长没前进 |
| 增速异常 | 超过阈值 |
| 自报不符 | 插件报的达标结论与服务端不符 |

**这些都只呈现给组长看，不自动处罚。**

## 九、邀请连带责任（新增）

**你邀请的人如果「死了」，你要担责。**

### 触发条件（满足任一）

| # | 条件 |
|---|---|
| ① | 被邀请人 30 天内**既没登录、也没有任何下载或做种记录**（死号） |
| ② | 被邀请人**因分享率被封禁** |

### 处罚（针对邀请人）

| 步骤 | 动作 |
|---|---|
| 1 | 扣 **100,000 瓶盖**（余额可以为负，显示为 0） |
| 2a | 你在保种组 → **立即清退**，账号进入 **1 个月考核期** |
| 2b | 你不在保种组 → **只扣款**，暂不考核 |
| 3 | 考核期满**余额仍 ≤ 0** → **封号** |

**设计意图**：邀请不是白给的资源，发出去就要对质量负责。但只对保种组成员追究到底——他们在岗、有义务。

## 十、常见问题

**我保到了 2T，为什么还没奖励？**
覆盖达标只是进入「待授予」候选池，要等**组长或 admin 授予「工作组-保种」**之后才开始计考核、发奖励。

**我不是工作组成员，能装插件吗？**
能。任何会员都能装、能保、能看自己的数据，只是不计考核、不发奖励。

**显示缺很多，但站点明明有那么多官种？**
插件只保**官方**种。官方池本身小于档位时，如实显示缺口——这是事实。

**我的覆盖突然变成 0 了？**
看面板上的标记。如果是「掉线」，说明连续 3 轮读不到你的下载器（网络问题或 qB 挂了）。偶发 1-2 轮失败会沿用上次读数，不会归零。

**想用 MP 的整理/刮削？**
用插件形态。独立 Docker 版刻意不含这些。

**退休后还能保种吗？**
能。权益全部保留，只是不再有月度义务和奖励。
