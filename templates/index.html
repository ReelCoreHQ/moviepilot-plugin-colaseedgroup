① 可乐PT API Key

在站点「账号 → Key → API Key」新建一把，范围勾「读取」和「下载」；接口说明见 www.colapt.com/api-docs

② 下载器

恢复做种时填原目录 + 开「跳过校验」即可续种
每行 地址,用户名,密码；Transmission 写 tr,地址,用户名,密码

⑤ 保种组

支持 0 */N * * *（每 N 小时）与 */N * * * *（每 N 分钟）
0 = 不限制
仅恢复做种时开；新下载开着会全部「丢失文件」

⑤-2 保种限速（只读）

0.6.0 起插件每轮只把客户端的限速读数报给站点（上传/下载，取多台里最紧的一台）， 不再给客户端写限速。要限速请在下载器里自己设，站点会按读数判定。
