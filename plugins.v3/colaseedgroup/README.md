# 可乐保种组（MoviePilot V3 插件）

按可乐PT 站点的**派单**把官种加进你的 qBittorrent / Transmission 长期做种。插件只是执行器：

- 站点决定派哪些种子给你（按你在站点申报的可提供空间、做种人少的优先）。
- 插件每轮拉派单：缺的加、站点**明确收回**的删；上报下载器里这些种子的状态。
- 保种奖励由站点按 tracker 实际观测到的做种情况、按体积计算，**不看插件上报**。

需要 MoviePilot **3.2.7 及以上**。

## 准备

1. 在可乐PT「账户 → Tracker → API」创建一把 API Key，勾选 **保种组（seedgroup）** 范围。
2. 在站点保种组页面申报可提供空间（≥ 2 TiB）。
3. 在 MoviePilot 里配置好下载器（只支持 qBittorrent / Transmission）。

## 设置项

| 设置 | 说明 |
|---|---|
| 可乐PT API Key | 上面那把 Key |
| 下载器 | 可多选；新种加到本插件管理种子最少的那台 |
| 专用保存目录 | 下载器视角的路径，默认 `/downloads/colaseedgroup`；只放保种组的种子 |
| 专用标签 | 默认「可乐保种组」 |
| 运行间隔 | 默认 10 分钟（也是最少） |
| 每轮最多加种 / 删种 | 默认 10 / 5，上限 50 / 20 |
| 收回时连文件一起删 | 默认开；内容被别的种子共用（辅种）时只删种子 |

## 插件会做什么、不会做什么

**只删自己的**：只有本插件加种成功时记过账的种子，并且它仍在原下载器、仍带专用标签、仍在专用目录下，
站点在本轮派单里明确收回时才会删除。你把它改了标签或挪出专用目录，插件就视为你接手了，不再删它。

**不接管**：派来的种子如果你的下载器里本来就有（你自己加的、辅种工具加的），插件只上报「已存在」，不记账、不删。

**出错不删**：站点连不上、返回错误或不合规、派单版本倒退、任一下载器列不出种子时，本轮一个都不删。

**不碰别的**：不改任何限速（全局、备用、乌龟模式、单种都只读），不动派单以外的任何种子（包括别站、馒头的种子）。

## 状态页

插件详情页显示最近一轮的结果（成功 / 站点错误原因 / 版本过低）、派单条数、本插件管理的种子与总体积。
下面的表列出站点派给你的**全部**派单（不只是插件加的）：种子名 | 体积 | 站点要求 | 本地情况 | 下载器 | 操作，
上方一行摘要「派单 · 插件管理 · 非插件管理 · 待加种 · 退避 · 收回」，分「异常 / 待加种 / 全部」三个筛选，每页 50 条。
「异常」只算要你自己处理的：加种失败退避中、下载器报出错或已暂停、所选下载器列不出种子；站点收回的派单由插件自己处理，不算异常。
tracker 有没有把它算作做种，以站点保种组页面（/account/seed-group）为准。

页面上的按钮：

- **立即同步**：马上跑一轮（照常遵守加种退避）。
- **重试加种**（单条 / 全部）：清掉加种失败的退避，马上同步。
- **恢复 / 重新校验**：只对插件管理的种子；已暂停的恢复，出错的重新校验。
- **接管**：下载器里本来就有的同一颗种子（非插件管理）。点「接管」后还要点「确认接管」：记进插件账本、打上专用标签，
  **不挪文件、不改保存路径**。接管后站点收回这条派单时会按插件管理的种子删除（共用内容时只删种子）；
  去掉专用标签就等于交还给你，插件不再删它。

站点要求的最低插件版本由站点下发；低于它时插件只上报、不加不删，请到插件市场更新。

## 常见问题

- **403**：Key 没勾 `seedgroup` 范围，或你还不在保种组。
- **种子一直在下载**：保种组的种子需要从别的成员那里下载完整后才开始做种；请保证下载器能连上 tracker。
- **我想退出**：在站点把可提供空间调为 0 或退出保种组，站点会逐步收回派单，插件按每轮上限删除。
